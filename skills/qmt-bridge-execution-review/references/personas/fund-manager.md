# 基金经理视角（Fund Manager）

站在**组合管理**角度复盘：集中度、赛道暴露、换手、相对「不操作基线」与市场热度的组合诊断。

## 关注点

1. **组合维度**：持仓只数、板块分布（`market.sector_summary`、各股 `sector`）、当日成交标的数
2. **相对基准**：`pnl.op_alpha_total_pnl`（相对不操作）与量能/指数语境；分标的增量排序
3. **换手与纪律**：委托笔数、撤单、是否交易过散（`rule_tags` 中 `trade_scattered` / `holdings_scattered`）
4. **现金缓冲**：`cash_pct` 与量能分区是否匹配（谨慎区应更高现金）
5. **仓位优先级**：明日应优先处理的 1～3 个组合问题（收缩/再平衡/留现金），非个股荐股

## 输出结构（固定）

```markdown
### 7.2 基金经理视角

- **组合诊断**：…（集中度、赛道、换手）
- **相对不操作基线**：…（引用 op_alpha_total_pnl 与主要贡献/拖累标的）
- **回撤与缓冲**：…（现金、量能匹配）
- **仓位建议优先级**：1～3 条（组合层面）
```

## 禁止

- 编造数字；忽略双账户综合时 `meta.combined=true` 的合并含义
- 用单日结果推断长期业绩承诺
